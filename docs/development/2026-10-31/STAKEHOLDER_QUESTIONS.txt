1. 가장 먼저 확보할 것
규정 자료는 상당 부분 확보했다. 이제는 “누가 어떤 조건에서 무엇을 할 수 있으며, 그 사실을 어떤 기록과 도구로 확인하는가”를 연결해야 한다.
우선순위 A: 이민준 → 사업 운영자 → 필요한 고길동 승인 확인, 시스템/API 담당 연결.
우선순위 B: 사건별 조회에 필요한 운송·생산·홍보·체험 기록과 갱신 방식.
우선순위 C: 경계 사례와 과거 예외의 승인·실행 결과를 검증 자료로 확보.
이 순서는 조사 제안이다. 공식 승인 요청은 상담→사업 운영자→교동 조합장 순서를 지킨다.

구현 연결: 접수→시설/일정 확인→가예약→담당 확인·조합장 승인→최종 확정.
주의: 이미 확인된 1회30명/일일약40명, 우천 연기1회/불가시 전액환불을 처음부터 재질문하지 않는다. 참가자 개별 명단·건강정보·동의서 원본을 추가 수집하지 않는다.

13. 운영·정산/증빙 담당 — 담당 실명부터 확인 [A~B]
질문
- 실제 증빙 종류와 API의 매핑, 상품/배송비 구분, 세율·포함 여부·반올림 및 부분환불 산식은 어디서 확인하나요?
- 발행·정정·취소·재발행의 중복 방지, 기존 증빙 교체, 월마감·휴일/마감 시각의 처리 기준은 무엇인가요?
- 회원 등급/누적액·승계 적립·단골가를 계산하는 원장과 갱신 시점은 무엇인가요?
확보: 증빙/정산 규격, 실제 결제·환불·증빙 상태 관계, 회원 원장과 계산 규칙.
구현 연결: 환불액·혜택·발행 잔액 계산 및 중복 발행 방지.
주의: 이 질문지가 실명이나 새로운 세무 규칙을 확정하는 것은 아니다.

14. 시스템/API 담당·시원배송 공식 접수 창구 — 별도 연결이 필수 [A]
이름은 아직 확인되지 않았다. 사업 운영자에게 담당 연결을 요청한다. 간선 기사 개인에게 직접 묻지 않는다.
질문
- 주문·결제·출고/집하 스캔·배송·온도·회원·쿠폰·정기배송·예약·증빙을 조회하는 API 목록과 요청/응답 샘플은 무엇인가요?
- 환불·재배송·취소·변경·예약·증빙·이관 중 실제 허용하는 쓰기 액션과 사전 승인 요건은 무엇인가요?
- 각 상태의 의미, 성공 판정, 멱등키, 타임아웃 후 결과 조회, 중복 방지, 오류·권한 거절 형식은 무엇인가요?
- 계정 인증·관리자 승인 증거는 신뢰할 수 있는 어떤 경로로 전달되며 고객 입력과 어떻게 분리하나요?
- 온도 로그 전체23행 중 미제공13행, 집하 스캔, 공식 담당/차량 최신 원장·변경 이력과 주문 연결 누락은 어느 조회/정정 경로에서 확인하나요?
- 테스트 환경·비식별 샘플·실행 제한·지연·유지보수/실패 시 공식 접수 방식은 무엇인가요?
확보: 신뢰된 API 명세·상태 정의·권한 규격·테스트 샘플·접수/정정 절차. 비밀키를 상담 기록에 붙여 넣도록 요청하지 않는다.
구현 연결: 실제 조회/처리 도구. 일반 HTTP 클라이언트가 있다는 사실만으로 업무 API 구현 완료라고 하지 않는다.

15. 모든 답변에 붙일 공통 후속 질문
“그 답의 근거 문서/기록과 위치, 기준일·시행일, 적용 주문/로트/행사, 직접 확인자, 승인 여부를 함께 알려 주세요. 기존 자료와 다르면 어느 부분을 정정하는지 구분해 주세요.”
답변은 확인된 사실 / 당사자 진술 / 해석·개발 제안 / 미확정으로 분리한다.
공식 문서·시스템 조회로 답할 내용을 사람 기억으로 대신하지 않는다. 자료가 없으면 담당 확인·이관 경로를 확보한다.

16. 언제 ‘완성’이라고 할 수 있는가 — 제안하는 완료 기준
- 주요 문의마다 적용 정책·필수 조회·가능 처리·승인/이관·실패 대응이 정의됨.
- 필요한 액션의 입력·권한·결과 판정이 실제 API와 연결되고 성공·실패·타임아웃·중복 상황을 검증함.
- 기존 정적 수용 사례를 실제 에이전트/도구로 실행하고 정답·처리·권한 위반 여부를 확인함.
- SimpleText 500자, 60초 무응답 경계, 최대10건 등 응답 제약을 모든 경로에 적용·검증함.
- 정보 부족·권한 밖 사건은 정확히 이관하고, 완료되지 않은 처리를 완료라고 안내하지 않음.
- 문서 정리, 런타임 반영, 검증, 배포 완료 상태를 따로 기록함. 기존 제출본 변경 금지·운영 유지 방침에 맞춰 배포함.
모든 사람의 모든 이야기를 확보해야 하는 것은 아니다. 지원할 업무의 필수 근거와 실행 경로가 완비돼야 한다.
