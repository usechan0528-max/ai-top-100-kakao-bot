중요한 최신 보완
docs/sources/action-api/INTRODUCTION.md에서 공식 공통 규약은 확보했다. API 전체 미확보라고 재질문하지 않는다. 개별 OpenAPI 스키마·공개 TC 전문·실제 TC 전달 형식은 추가 검수 대상이다. 접수 API는 요청 기록이며 상태/금액 변경이 아니다. 성공 응답을 환불 완료·변경 완료로 해석하지 않는다.

목적: 개별 액션 입력/응답·실제 케이스 경계. 먼저 개발자가 기존 공식 문서의 Download OpenAPI Document와 공개 TC 탭을 확인한다. 등장인물에게 API 주소/필드를 반복 질문하지 않는다. 토큰 평문을 채팅에 요청하지 않는다.
