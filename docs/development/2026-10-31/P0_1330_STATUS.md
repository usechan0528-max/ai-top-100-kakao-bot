# 13:30 P0 후속 구현

작업일 2026-10-31. [사용자 원문](../../sources/action-api/P0_1330_TRANSCRIPT.md). 제출 목표 14:40, 제출/배포 완료 아님.

현재 코드 확인: Worker는 createScopedActions의 대화별 도구 목록을 runAgent에 전달한다. 정적 actions export는 달력만이며 실제 상담 전체 목록과 다르다. 주문·결제·배송 조회 5종은 ACTION_TOKEN 및 유효한 ACTION_READ_BINDINGS가 있는 경우 등록된다. 이번 작업 중 다른 변경으로 배송 조회와 진단 경로가 추가된 것을 확인했고 보존했다. 전체 액션/쓰기 연결 완료로 확대하지 않는다.

변경: 명시 TC ID/TC/id/헤더 표기 및 /조회 명령에서 TC를 추출한다. 여러 TC 또는 잘못된 형식은 기존 상태를 바꾸지 않고 거절한다. 사용자+채팅방 Durable Object의 별도 테이블에 TC를 저장해 재시작/다음 메시지에서도 유지한다. TC 전환은 모델 생성 전에 요약과 조회 상태를 제거한다. 이벤트/쓰기 중복방지 기록은 유지한다. /초기화는 대화 요약/조회 기억만 지우며 현재 TC와 외부 데이터는 유지한다.

모든 등록 조회의 TC 헤더는 서버 클로저로 고정하며 모델 인자로 변경할 수 없다. TC와 서버 회원 바인딩이 다르면 개인 도구를 제공하지 않는다. 이전 회원을 새 TC의 고객으로 추정하지 않는다. 회원 로그인 정보 인증 효력은 사용자 후속 답변에 따라 미확정이다.

토큰 이름: 런타임 참조와 답변 가림은 ACTION_TOKEN. ACTION_TOKEN_FILE은 로컬 검사 파일 위치 변수이며 별도 비밀값 이름이 아니다. 클라우드 재등록은 총괄자 담당이며 이번 작업에서 등록·열람하지 않았다.

reset API는 도구 등록/호출하지 않는다. 관리 진단의 공개 예시 기본 TC는 L-03이며, 카카오 진단 명령은 저장된 TC가 있으면 그 값을 사용한다. 관리 진단은 실제 고객 처리 성공 증거가 아니다.

검증: START_DEV.cmd check 문법26파일, 테스트202/202, 오프라인 데모 통과. 새 TC 추출/충돌·재시작·기억삭제·모든 조회 헤더/토큰·reset 부재 회귀검증 포함. 기존 500자 최종 응답 검사 통과. 실제 모델·액션 서버·카카오 종단·배포는 이번 작업에서 수행하지 않았다.

남은 제출 조건: 실제 인입 회원 문맥의 신뢰 근거 확인 및 TC별 회원 바인딩, 필요한 쓰기/전체 액션 범위 구현·검증, ACTION_TOKEN 재등록 확인, 실제 상담 종단 및 배포 검증. 따라서 P0 전부 해소/제출 가능으로 표기하지 않는다.
