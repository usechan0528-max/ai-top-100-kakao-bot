# 영업일 달력 로컬 런타임 적용 및 검증

작업일2026-10-31, 시나리오2037-06-30. 사용자 요청에 따라 달력 계산을 실제 코드·런타임 정책·Worker 도구 등록에 반영했다. 클라우드 배포나 실제 모델/업무 API 호출은 수행하지 않았다.

## 구현

- `src/business-calendar-data.mjs`: 검수된 원문 시트8의03-02~12-31 날짜별305행을 동결 상수로 공급한다. 기준일·원본 SHA-256·범위를 포함한다. 생성 스크립트 `scripts/build-business-calendar.mjs`는 셀 전사에서 읽으며 실제 공휴일 서비스나 현재 서버 날짜로 대체하지 않는다.
- `src/business-calendar.mjs`: 날짜 조회, 영업일 순산, 결제일 제외3영업일 역산, 당일 포함 다음 정기 출고 후보, 월집계 및 가정상 현지시각 비교. 범위밖 날짜·부족한 계산범위는 확인 필요로 반환한다. 휴무 접수는 다음 영업일을 기준일로 옮긴 뒤 다시 제외한다. 휴무 결제일은 임의 이동하지 않는다.
- `src/worker.mjs`: `business_calendar` 읽기 전용 로컬 도구를 실제 Worker의 actions에 등록. 개인정보·외부 API·쓰기 기록을 사용하지 않는다. 일반 `runAgent` 호출자가 도구를 전달하지 않는 환경에서는 도구가 자동 등록되지 않는다.
- `src/business-policy.mjs`: 날짜 계산 시 등록 도구 사용,7종 기한 단위·개별 명시 단위·역일 연휴 처리, 수확/출고후보/실제확정 구분, 공휴일 회차 스킵, 연휴 면책 범위, 실제 요청시각 미확정 처리를 추가했다. 기존 SYSTEM_POLICY→모델 instructions 경로로 전달된다.

## 미확정 기준의 처리

컷오프 계산의 날짜와24:00은 제공 근거로 확정하되 `timeZone:null`, `boundaryInclusive:null`, `requestTimeBasis:null`, `applicability:needs_confirmation`을 유지한다. D일24:00은 다음날00:00 현지 경계로만 표현한다. 내부 UTC 날짜 연산은 날짜 자리올림을 위한 것이며 업무 시간대를 UTC로 지정하지 않는다.

`compare_cutoff`는 가정한 같은 현지 시계의 before/equal/after만 제공한다. 실제 시스템 요청시각의 의미/정밀도/시간대가 확인되지 않았으므로 모든 비교에서 `applicableCycle:null`·확인 필요를 반환한다. 정각과 다음날00:00을 같은 경계로 정규화하되 포함 여부는 정하지 않는다. 모델 인자에 inclusive/verified/timezone 등을 추가하여 정책을 확정할 수 없다. 오프셋을 붙인 시각·잘못된 날짜/시각은 거부한다. 향후 공식 시각 규격 확보 후 별도 검증을 거쳐 실제 반영회차 판정기를 연결해야 한다.

이 도구는 환불/스킵/해지 접수나 승인 도구가 아니다. 실제 주문 출고일도 확정하지 않는다. 언어모델이 지침을 항상 준수한다는 보장은 로컬 모의 검증으로 입증하지 않았다.

## 실행한 검증

`START_DEV.cmd check`: Node v24.19.0, 문법17파일·테스트148/148·오프라인 데모 통과. 기존126개+신규22개.

신규 검증:305일 전수 원문 대조,10개월 합계, 순산6건(휴무접수2건 포함), 역산5건, 휴무 결제일 비이동, 휴일 회차 스킵/수확 후보, 범위/날짜/일수 오류, 마감 직전·정각·직후와 D24:00=다음날00:00, 잘못된 시간/시간대·모델 인자 정책 덮어쓰기 차단. Worker 등록 도구→모델 어댑터의 모의 함수 호출→실제 계산→단일 SimpleText500자 이내 콜백 흐름을 검증했다. 읽기 도구는 쓰기 저널을 예약하지 않는다. 실제 모델 호출은 없으며 모의 모델의 답변은 테스트 입력이다.

첫 신규 통합 테스트는 테스트 코드가 도구 결과의 래퍼 필드를 `value`로 잘못 읽어 실패했다. 기존 계약의 `result`로 테스트를 수정한 뒤 전체 검사에 통과했다. 프로덕션 결과 형식은 변경하지 않았다.

남은 확인: 실제 모델의 도구 선택/업무 정답률·인젝션 내성, 실제 요청시각 규격/공식 컷오프 대조, 공식 업무 액션 연결, 카카오 실수신·클라우드 배포. 임시공휴일 변경본이나2038년 등 범위밖 자료는 후속 원문 검수 후 정적으로 갱신한다. 제출 후 변경 금지·운영 정책을 유지한다.
