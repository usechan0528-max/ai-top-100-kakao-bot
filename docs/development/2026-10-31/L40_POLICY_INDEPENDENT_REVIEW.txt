L40 반복 대량구매 정책 보완 독립 검토
검토일: 2026-10-31 / 시나리오 기준일: 2037-06-30

범위
- src/public-tc-policy.mjs의 L40 추가 두 문단(검토 시점 10~11행)을 읽기 검토했다.
- 필수 개발 지침과 BUSINESS_CONTEXT, 공식 L-40 원문, PUBLIC_TC_GUIDE의 L40 절, 운영규정 원문 제19·20조를 대조했다.
- 실제 도구명과 반환 경로는 src/member-actions.mjs 및 src/order-payment-actions.mjs에서 확인했다.
- 소스 수정, 테스트 실행, 외부 API, CUA, 배포는 수행하지 않았다.

판정: 검토 범위 내 수정이 필요한 확정 결함 없음.

원문 기대 대응과의 대응
1~2. 회원 이름·고객 제공 연락처 대조 후 해당 회원 주문 이력을 조회하도록 연결한다. 정책의 list_my_orders는 실제 등록된 API08 도구명과 일치한다. 회원 대조를 독립 로그인 인증으로 승격하는 문구는 없다.
3. 최근 2주 유사한 도매급 반복 구매 이력이 확인된 L40 상황에서는 이번 수박 구매의 단골 쿠폰·소매 할인 적용 불가를 명시한다.
4. 개인 소매계정의 도매급 반복 구매에 대한 조합 규정상 혜택 제한을 사유로 설명한다. 구매확정액에 따른 단골등급 판정과 별개임을 명시하여 기존 실제 답변의 회피 원인을 보완했다.
5. 사업자등록증을 이용한 도매 거래처 등록 절차를 안내한다. 물량별 단가·전자세금계산서는 운영규정 제19조 근거와 일치한다.

과장·오판 방지 경계
- 한 번 50통 구매만으로 모든 고객을 도매로 분류하거나 실제 재판매를 단정하지 않는다.
- 조회 실패, 귀속 미확인, 반복 이력 미확인, 취소·실패 주문만으로 혜택 제한 근거를 만들지 않는다.
- 원문에 없는 보편적 수량 기준, 구체 단가, 등록 승인·완료를 창작하지 않는다.
- 내부 회원 ID·다른 고객 이력을 고객에게 공개하지 않는다.

검증 한계와 다음 확인
- 이번 결과는 문구·근거·실제 도구명에 대한 정적 검토다. 모델이 보완 후 실제 카카오 응답에서 기대 대응 3~5를 함께 안내했는지는 별도 실증이 필요하다.
- 이전 배포에서 회원 대조와 4건의 반복 이력 조회에 성공했다는 내용은 담당자 보고이며 이번 독립 검토에서 재실행하지 않았다.
- 배포 완료, 전체 검사 통과, 500자 이내 실제 응답 달성을 이 문서의 독립 검증 결과로 주장하지 않는다.
