- 이전 조직관계도 ‘취급 품목11종’과 농산10·수산2의 수 불일치는 이 자료로 해소되지 않는다. 참조 제목 ‘1차6종+수산물’이나 ‘전 품목’으로 전체 개수를 추정하지 않는다.
