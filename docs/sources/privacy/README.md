## 상충·미확정·참조 문서

1. 제8조③의 ‘목적이 끝났는지’와 ‘별도 근거가 있는지’에 대한 ‘둘 다 아니면 파기’는 제8조①과 논리 관계가 불명확하다. 원문을 교정하지 않았다. 해당 문구에 의존하는 자동 파기/보유는 담당 판정 필요. 판정 지연을 무기한 보유 근거로 삼지 않으며 명확한 의무는 분리한다.
2. 제14조의 본인 명의 계좌 재요청은 판매·환불 제12조⑤ 원결제 계좌 확인과 함께 적용한다. 본인 명의 다른 계좌 허용 근거는 확인되지 않았다. 제9조의 정보 대조는 아는 정보만으로 인증 불가라는 환불 규정의 폐지가 아니다. 정식 인증 성공 기준은 미제공이다.
3. 상담3년/거래5년 보존은 제공 방침의 내용이며 실제 법령 검증을 수행한 것이 아니다. 단기 대화 요약30분·쓰기/이벤트24시간·원문 미보관이라는 현재 구현 기록과 다르다. 업무 보관 원장·요구 기록·민감값 제외 및 파기 구현은 미확인/미구현 범위이며 문서 작성으로 준수 완료라 하지 않는다.
4. 제8조 일반 파기와 제21조 법정 기록 제한을 함께 적용한다. 상담 기록에 포함될 수 있는 본인확인 값·배경 정보·환불 계좌·자격증명의 구체 마스킹/보관 분리 설계는 추가 구현 과제다. 제23조 사건 기록에 실제 비밀값을 복제하지 않는다.
5. 참고 전문 미확보: 갯마을↔교동 위탁 계약, 제3자 정보 보호 조항, 조합 규정집 제8~10조, 사업자정보, 농가 이야기, 에스컬레이션3레인, 개정이력/구판·개정판·부칙/경과규정. 기존 배송 계약은 확보했지만 동명 참조 문서의 파일/버전 일치까지 검증한 것은 아니다. D37 공시 예시값과 조직 내부 농가정보는 실제 공시/공개용 스토리를 대체하지 않는다.
6. 미확정: 보유기간별 기산점·백업/복제본 파기 범위, 행사 미개최 시 보유 기준, 공식 영업일 달력·10영업일 기산/시각, 본인확인·귀속 검증 API, 요청 기록/파기 도구, 전용 이관 담당·경로, 공식 재설정·유효 연락처. 법적 요청의 자료를 봤다는 것만으로 적법한 제공 권한이 생기지 않는다.
