1. PDF §7 ‘11종’과 실제 농산10·수산2는 불일치한다. 원문 유지·임의 품목 추가 금지.

3. ‘새 환불 정책 창작 불가’와 조합장의 ‘정책 변경 최종 승인’은 상담에서 정책 창작 금지와 정식 승인 절차를 구분해 적용한다. 정식 정책 변경 절차 전문은 미제공.
