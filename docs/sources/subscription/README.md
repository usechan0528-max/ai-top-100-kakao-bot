## 기존 자료와의 관계·미확정

- 판매·환불 제15조의 언제든 해지와 본 약관은 해지 요청 가능 여부와 회차 반영 시점을 구분한다. 제23조의 미확정 회차 마감 계산 방식은 본 제3·9조로 보완됐다. 개별 회차 실제 마감값은 여전히 조회해야 한다.
- 배송 계약의 일반 집하 전 취소 가능과 본 제6조의 컷오프 후 출고 준비 전 취소는 조건 범위가 다르므로 잠재적인 결론 차이를 명시했다. 본 약관 제1조의 보충 관계로 판단하고 해소되지 않는 실제 충돌은 판매·환불 제19조도 적용해 확인한다. 출고 준비를 집하와 같은 단계로 합치지 않는다.
- 본문이 참조하는 「판매·환불 규정」은 앞서 받은25조 규정, 「택배사 계약서」는 기존12조 배송 계약과 조문 내용을 대응시켰다. 원문 제목은 수정하지 않았으며 파일·버전 동일성을 추가 검증한 것은 아니다.
- 「영업일·공휴일 달력」 전문은 미제공이다. 실제 세계 달력으로 시나리오 일정을 대체하지 않는다. 약관 시행일·버전, 시스템 시간대, 요청 시각 정의/정밀도·정확히 컷오프와 같은 순간의 포함 여부, 사전 안내2영업일 전의 세부 마감시각, 출고 준비 상태 판정 필드, 개별 회차·결제·스캔·알림 기록·API는 미확정이다.
- 신규 자료의 ‘회차 결제’ 목적만으로 결제 실패 재시도·청구 시각·부분 결제·자동 환불 세부를 만들지 않는다. 등록 알림 수단이 없더라도 화면 안내가 기본이다.
