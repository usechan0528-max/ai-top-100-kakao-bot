## 기존 판단 정정·남은 범위

D37 전사190~193과 새 공시 값은 일치한다. 그러나 이전 BUSINESS_CONTEXT:513·privacy/README:44·backlog의 ‘예시라 고객안내불가’는 당시 개발 판단이며 새 공시 원문과 충돌한다. **이번에 확보한 공시 페이지에 적힌 값은 시나리오 고객 안내 근거로 사용할 수 있다.** 0이 많은 값이나.example도 추측 교정하지 않고 그대로 안내한다. 이민준은 기존 값의 예시 여부를 단정하지 않았으므로 ‘이민준이 예시라고 확인’으로 쓰지 않는다. 실제 세계 사업자등록·전화/메일 유효성 검증이나 현실 연락처라는 주장은 하지 않는다.

정확 공시 위치는 조합몰 사업자정보 페이지와 제공 원본 URL이다. 미확보공시라는 과거 상태를 이번 확보 범위에서 해소한다. 개인정보/제3자정보 원문이 정한 개인 배경·가족·매입가·계약조건 제외는 유지하며 이 페이지에 구체적 제외조항이 있다고 허위 인용하지 않는다.

문서 전사/정적 가이드 완료와 런타임·배포·Y24 실제 모델/카카오6항 검증은 별도다. Y07 음성 전사 등 다른 미처리 자료를 완료로 바꾸지 않는다.
