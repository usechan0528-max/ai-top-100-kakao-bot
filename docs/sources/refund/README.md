## 상충·추가 근거·처리 상태

배송 계약의 파손 클레임은 포장만/내용물 하자를 구분해 연계한다. 내부 정산보다 고객 구제 우선 원칙과 직접 충돌은 확인되지 않았다. C54의 경미 지연은 하자가 아니라는 설명을 제14조 출고 지연 취소·장기 보상 거절로 확대하지 않는다. D37 탈퇴 후 일반 하자 보상은 유지된다. 제4조 선택권과 제7·9조 등의 처리 결론은 사건별 요건을 대조하고 제19조로 판단하며, 미제공 품목 특칙을 추정하지 않는다.

미제공: 부분환불 산식과 전량/부분 경계, 당도 보장 카탈로그·품목 특칙, 개정 전 제6·20조, 조건부 주문 실제 조건, 저울/당도 확인 절차, 차액·반올림, 7일 기산·시각, 장기 대기 기준·보상액, 재량 한도·정식 인증·배상 절차 세부·회차 마감·실제 API. 제20조 이전 수령 적용 특례를 제6조에 확대할 근거는 없다.

25조·별표·부칙 전사 및 위27행의 가이드 대응을 정적 대조했다. F-T01~30은 작성된 수용 사례이며 실행 테스트가 아니다. 원문·분야 가이드·업무 기준·색인과 기존 관련 분야 연결을 갱신했다. 현장 조회·코드·런타임 적용·실행 검증·배포는 미수행이다.
