## 상충·미확정·근거 구분

- 제공 시나리오의 세액·기한·자율 발급 안내를 보존했다. 실제 세법 적합성·국세청 절차를 검증한 보고가 아니다. 원문의 ‘전자세금계산서’ 명칭과 면세 상품/과세 용역의 실제 증빙 종류 매핑은 API·업무 규격 추가 확인 대상이다.
- 개인의 현금영수증 지출증빙용 요청 가능은 개인 결제분을 사업자 명의 세금계산서로 바꿀 권한이 아니다. §7 실제 결제자 명의 대안도 §6의 발행 자격 안에서만 적용한다.
- 사업자 거래와 카드/현금은 분류 축이 다르므로 사업자 카드 거래·기발행 증빙 교체/중복 규칙은 미제공. 발행 전 부분환불 후 잔액 신규 발행 여부도 원문만으로 확정하지 않았다.
- §4 확인 즉시/사유 발생일 기준과 §3 소요1~2영업일은 처리 기준과 완료 소요로 구분했다. 마감 후 취소/수정 발행일은 환불 승인일이며 기한 지난 최초 발행 소급 허용과 다르다.
- §5 적립금 환불은 증빙 정정 예외일 뿐 원결제수단 환불을 적립금 지급으로 대체할 근거가 아니다. 확정된 환불액만 반영하고 별도 부분환불 산식을 창작하지 않는다.
- 개인정보 방침의 번호 선낭독 금지·계정 귀속·최소수집을 유지한다. 이번 자료의 사업자등록증/수취 이메일 등 증빙용 수집 요구와 개인정보 방침 제4조 ‘다음 항목만 수집’의 상세 목록 관계, 보유/파기 범위는 추가 확인 필요. 임의 장기 보관 권한으로 확대하지 않는다.
- 미확보 전문: 사업자 도매 거래 안내/거래처 등록, 증빙 권위 서열 조항 제3·9조, 부분환불 산식·박스 비율 임계표. 공식 영업일 달력·세율·부가세 포함/반올림·기한 시각/휴일 연장·월마감 정의·증빙별 정정 API·국세청 자율 발급 상세·담당 권한도 미제공이다.
- 상담 예시의 ‘발행 완료’는 실제 처리 기록이 아니다. 홈택스 다음 영업일 조회는 통상 안내이며 연말정산 자동 반영 문구를 지출증빙까지 일괄 확대하지 않는다.
