# 대회 평가 기준 사용자 제공 원문

출처: 이 대화의 사용자 메시지. 수신일 2026-10-31. 방법: 채팅 제공 텍스트 전사(OCR 대상 아님). 줄 간 빈 공간은 정리했으며 내용·번호·강조·링크와 후속 정정을 구분해 보존한다. 원문 속 ‘5번’은 삭제하지 않고 정정 이력으로 해결한다.

## C-S01 최초 제공문

1. **에이전트 응답 속도(p95)**
   - **개별 말풍선 응답 속도(latency)를 측정해 평가합니다.**
   - **빠를수록 배점이 높습니다.**
2. **에이전트 응답 메시지 평균 말풍선 수**
   - **케이스별 참가자 에이전트가 보낸 응답 메시지 말풍선 수를 평가합니다.**
   - **적을수록 배점이 높습니다.**
3. **에이전트 응답 메시지 말풍선당 평균 글자 수**
   - **응답 메시지 말풍선 하나에 담긴 평균 글자 수를 평가합니다.**
   - **적을수록 배점이 높습니다.**
4. **케이스 응답 정확도**
   - **확인된 지식과 근거, 고객 문의의 맥락, 운영 정책에 맞게 답했는지 평가합니다.**
   - **액션 서버 API 호출 등 필요한 조회·처리·이관의 수행 여부와 정확성을 평가합니다.**

**2, 3, 4번 항목은 5번 항목의 점수에 따라 가중치가 적용됩니다.**

**응답 메시지 유형**

[**SimpleText(텍스트만 포함되는 말풍선)**](https://developers.kakao.com/docs/ko/bot/rest-api#simple-text)**가 아닌 응답일 경우 해당 케이스를 종료하고, SimpleText 메시지까지만 평가합니다.**

**60초 이상 무응답**

**해당 케이스를 종료하고 직전 메시지까지만 평가합니다.**

**응답 메시지 10건 도달**

**케이스당 최대 응답 메시지 수는 10건이며, 10번째 메시지까지 평가한 뒤 종료합니다.**

**답변을 나누어 전송**

**나눠 보낸 말풍선은 각각 1건으로 계산합니다.**

**답변 글자 수 초과**

**에이전트 답변은 말풍선당 최대 500자 이내여야 하며, 초과 시 평가에서 제외되나 응답 메시지 수(10건)에는 차감됩니다.**

**운영측 에러로 평가 중단**

**중단 직전 메시지에 이어서 재진행합니다.**

**종합 점수 동점**

**종합 점수가 동점일 시 최종 제출 완료 시각이 빠른 참가자를 우선합니다.**

대회 기준입니다. 문서화 시켜서 개발 지침으로 하십시오

## C-S02 사용자 후속 정정 원문

5번은 신경쓰지 않아도 됩니다 123 항목이 4번 점수에 따라 가중치를 적용받습니다

## 전사자 주석

적용 기준은 C-S02에 따라 **1·2·3번에 4번 정확도 점수에 따른 가중치 적용**이다. 정량 배점·가중치 공식·공식 글자 집계 방식·latency 측정 시작/종료점은 원문에 없다. 링크는 제공 출처로 보존했으며 최신 웹 규격을 추가 조사한 기록은 아니다.
