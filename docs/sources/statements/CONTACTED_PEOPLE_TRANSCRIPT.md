## U03 조억만 고객 소개 — 제공 원문
조억만 고객님 연락처 줄게. 조합몰 개장 초부터 온라인 상담으로 응대해 온 단골이야. 얼굴은 본 적이 없고, 상담으로만 계속 이야기해 왔어.

고객님께는 구매하고 상담받고 처리받았던 경험을 직접 물어보면 돼. 조합 업무 담당자는 아니라서 조합 운영에 관한 건 고객님을 통해 알아볼 수 없어.

### U03 출처·검수·상충
실제 수신/작업 2026-10-31, 시나리오 기준 2037-06-30. 사용자 제공 텍스트 2문단·5문장 전체 보존. 첨부·표·각주 없음, 판독 불확실 없음. 소개 화자 실명 미표기이며 사용자의 실제 신원으로 간주하지 않는다. 연락처 제공 의사만 있고 실제 연락처 값·새 대화 전문은 없다.

고객 지위, 개장 초기부터 온라인 상담으로 응대한 단골이라는 소개, 소개 화자와 비대면 상담 관계, 구매/상담/처리 경험의 직접 확인 가능 범위, 업무 담당자 아님/운영 확인 불가를 각각 보존했다. '단골' 표현만으로 공식 회원 등급·누적 구매액은 확정하지 않는다. 기존 고객-조합장 대면 친분 자료와 이번 화자의 비대면 관계는 주체를 분리한다. 이번 화자를 조합장으로 특정하거나 기존 관계의 고객을 조억만으로 특정하지 않는다.
