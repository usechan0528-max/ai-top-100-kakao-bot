## 확인된 사실과 해소된 공백
- 운영자 실명은 이민준(10조①). 이전 사업 운영자 실명 미확정을 해소한다. 상담 에이전트와 운영자 승인 역할은 분리한다.
- 일반 상한5만원, 확인된 하자 전액환불/재배송 및 특정 규정상 반환은 금액무관 예외. 반환과 추가보상 합산 분리.
- 승인3영업일·명시회신/기록·무응답 승인 불가. 무조건 미래 약속은 조합장 승인으로도 금지. 과거 과잉약속은 인정/정정/1회분 보정.
- 레인 매핑 일부와 필수3단 범위 확보. 전문3레인/정식승인/API까지 확보한 것은 아니다.

## 문언 경계·추가 확인 사항
1. 4조②/5조는5만원 초과 및 정책예외의 최종 승인자를 조합장으로 명시하고,10조①은 금액초과/정책예외가 운영자 판단으로 종결될 수 있다고 한다.10조②의 운영 경유는 명확하다. 운영자 독자 종결의 구체 위임 범위/수치와 적용 예시는 미제공. 원문 모두 보존, 운영자1차 판단·권한근거 확인, 필수3단 준수. 일률 직접 조합장 요청/일률 운영 승인완료를 만들지 않는다.
2.10조④의 운영자 부재 대체 참조 제목은 구방만→박민아 기록이나 확보된 C31은 배송대행이다. 운영 승인권 대체자/정식 위임 근거를 확보하지 않았으므로 기사에게 승인권을 부여하지 않는다.
3.5조④ 즉시 이관 분쟁/법률은 레인② 안전·법률인데10조③2호는 손해배상/분쟁/법률에서 레인③을 참조한다. 원문 보존, 정식배상과 분쟁/법률 상세 레인 경계는3레인 전문 확인. 필수조합장 판단과 즉시이관은 유지한다.
4. 프로모션 원혜택/가격인하 최소쿠폰이5만원을 넘을 때 일반 상한과의 관계는 별도 확인. 금액무관·재량 예외를 자의 확대하지 않는다.
5.3영업일의 기산점/시각/달력, 승인 기록 필드/권한검증/명시회신 형식, 부분환불 산식·쿠폰마스터·개정이력·과거상담 정본·승인/티켓 API는 미제공.
6. 사용자 제공 ‘조합장인 저’는 시나리오 진술이며 사용자 본인 신원 인증·특정 주문 승인으로 쓰지 않는다. 내부 위임표 원문은 고객 공개 응답으로 복사하지 않는다.
