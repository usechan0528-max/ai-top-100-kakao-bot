# 교동마을 체험 운영 기준

## 2. 적용 범위와 개인정보 처리방침

교동마을 농촌 체험·견학 프로그램의 문의 접수, 예약, 시설·안전 확인에 적용한다. 과거 행사에서 실제로 어떤 정보를 받았는지와 그 명단의 보유 상태는 「과거 행사 목록」에 기록한다. 과거의 접수 방식이 현재의 수집 근거가 되지는 않는다.

개인정보 처리의 일반 기준은 「개인정보 처리방침」, 제3자 정보 보호는 「제3자 정보 보호 조항(공급자·직원·수령인)」을 따른다. 「개인정보 처리방침」 제5조②의 확정 후 별도 동의 수집은 필요한 범위가 있는 경우의 일반 기준이다. **이 체험 프로그램에서는 문의 접수·가예약·최종 확정 어느 단계에서도 참가자 개별 명단을 받지 않는다.** 인솔 단체가 보험 가입과 법정대리인 동의 취합·보관을 맡고, 조합은 책임자에게 취합 완료 사실만 확인하는 방식으로 운영한다. 확정 뒤에도 조합이 참가자 개별 신원이나 동의서 원본을 추가로 수집하지 않는다.

## 4. 예약 절차

문의 접수, 가예약, 최종 확정을 구분한다. 문의 접수 시 예약 가능 여부를 확정하지 않는다.

|단계|처리 내용|수집 정보|
|---|---|---|
|① 문의 접수|최소 정보만 확인 · 가/부를 단정하지 않는다|책임자 성명·연락처 · 총 인원 · 연령대(구간) · 희망 일정|
|② 가예약|시설·활동·안전 확인 후 **같은 채팅으로 회신** → 고객 선택 → 예약 일정 확보|추가 수집 없음|
|③ 최종 확정|안전·보험·시설 확인이 끝난 뒤에만 확정한다|그 단계에서 **필요한 최소 정보만** 추가로 받는다|

확정 단계의 추가 최소 정보는 **인솔 책임자에 관한 정보와 동의 취합 완료 사실**까지이며 참가자 개별 신원이 아니다. 고객용 예약 안내와 확인 후 회신 절차는 「체험 프로그램 안내 팸플릿」을 따른다. 가예약 유지 기간·결제·조합 승인에 관한 고객 안내도 「체험 프로그램 안내 팸플릿」에 있다.
