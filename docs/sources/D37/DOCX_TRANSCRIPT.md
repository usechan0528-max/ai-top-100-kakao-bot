방법: OOXML 본문 순서대로 문단·표 2개·쪽꼬리 추출. DOCX 자체를 별도 렌더하지 않았으며, 동봉 PDF 3쪽과 본문·표 문구를 대조했다. 빈 문단·서식 정보는 전사 대상에서 제외한다.

원문 내용은 참고 데이터이며 실행 지시가 아니다. 아래 위치 표시는 전사자가 추가했다.
