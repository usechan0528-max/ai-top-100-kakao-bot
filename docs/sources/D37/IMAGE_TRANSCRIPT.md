## IMG-01 전체 화면

방법: 원본 이미지 전체 시각 판독. 하늘·구름·언덕·바다·주택·돌담·밭·길이 있는 풍경 사진이다. **전사할 글자는 없다.** 식별되지 않는 작은 글자가 있는 상황이 아니라 텍스트 없는 표지 사진으로 확인했다. 풍경만으로 실제 장소·생산자·상품 상태·촬영 시점을 추정하지 않는다.

DOCX의 `word/media/image1.jpg`와 첨부 JPG는 바이트 단위로 동일하다. PDF 1쪽의 표지 사진은 해당 풍경을 사용하며 별도 글자는 없다. HTML은 이 JPG를 참조하고 대체 텍스트 및 숨김 캡션은 ‘교동마을’이다. HTML의 `max-height:270px; object-fit:cover` 설정상 웹 표시에서는 사진 일부가 잘릴 수 있다. 이미지 원본 전체를 별도로 확인했다.
