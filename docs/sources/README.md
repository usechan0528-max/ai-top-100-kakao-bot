## 공통 검수 원칙

- 텍스트 원문은 직접 전사·추출하고, 이미지·스캔은 OCR 또는 시각 판독한다. 이미지에 글자가 없으면 그렇게 기록한다.
- 파일 이름이 같거나 내용이 유사해도 개별 파일·페이지·표·각주·별표 범위를 확인한다. PDF와 PNG가 같은 내용이라고 가정하지 않는다.
- 내용 누락 검수는 각 묶음의 대조표를 기준으로 수행한다. 판독 불가와 자료 자체의 미제공·불일치를 구분한다.
- 전사 자료에서 참조만 된 문서는 확보로 표시하지 않는다. 인용 문서의 전문·개별 주문 상태·API·권한 수치는 후속 제공 시 보완한다.
- 업무 기준은 [BUSINESS_CONTEXT.md](../BUSINESS_CONTEXT.md)에 누적하고 [분야 프롬프트 색인](../prompts/README.md)을 함께 갱신한다.
