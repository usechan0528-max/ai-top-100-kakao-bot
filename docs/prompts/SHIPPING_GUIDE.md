## S01 역할·정의·필수 조회 (제1~2조)

갑은 교동마을 산지직송 조합, 을은 주식회사 시원배송이다. 계약은 농·수산물의 집하·운송·배송 기준과 책임 배분을 다룬다. 집하는 출고지에서 을이 물품을 인수해 운송을 개시하는 것, 고객 귀책은 수취인 부재·주소 오입력 등 수취인 측 사유, 합포장은 동일 수령지 복수 주문을 하나의 포장으로 발송하는 것이다. 배정 기사는 출고지 상주 집하 담당자로 구간별로 구분한다.

문의에 필요한 항목만 조회한다: 주문·품목·수령지, 송장 등록 시각, 을의 집하 스캔, 배송 현재 상태, 반송·재배송 여부, 보관 조건, 최초 출고일·회차·잔여 도착 예상, 비용·귀책 근거, 현장 인계·대행 기록, 상담 재량 한도. 이미 아는 정보는 재질문하지 않는다.

## S02 단계·변경·취소·송장 (제3조, 제10조③)

물품 준비 → 송장 등록 → 집하(출고) → 배송 중 → 배송 완료 → 구매 확정 순이다. 송장 등록은 집하 완료가 아니다. 변경·취소 가부는 **을의 집하 스캔 기록 시각**으로 판정한다. 출고지 인계 진술과 달라도 이 판단에는 스캔을 우선한다.

집하 전에는 배송지 변경·취소가 가능하다. 집하 후에는 변경할 수 없으며 수취 거부 시 자동 반송된다. 자동 반송을 자동 환불·무료 재배송과 동일하게 안내하지 않는다. **반송 건을 재배송할 때의 주소는 주문 배송지 변경 요청으로 받고 집하 후 제한을 적용하지 않는다.** 일반 진행 중 배송 변경과 이 예외를 먼저 구분한다.

송장 등록 후 조회 반영은 통상 3~5시간 걸릴 수 있으며 그 사이 미조회는 정상이다. 이를 지연·사고로 판정하지 않는다. 5시간 초과만으로 사고를 확정하지 말고 실제 기록을 확인한다. 조회 실패를 스캔 없음·집하 전으로 간주하지 않는다. 변경 직전 최신 상태와 처리 결과를 확인해 경합을 줄인다(개발 방침).

## S03 배송 소요·대량 배차 (제4~5조)

구체적인 기상·결항·집하 재개 사건은 기존 [C54 기상·운송 가이드](WEATHER_TRANSPORT_GUIDE.md)를 함께 적용한다. 일반 운송 일지를 개별 주문의 집하 스캔으로 대체하지 않는다.

당일 배송은 불가하고 통상 **주문 다음 날~모레** 도착한다(사용자 설명). 긴급 출고도 지역·기사 사정, 기상특보, 항공·선박 결항, 도로 통제로 지연될 수 있다. 통상 예상과 보장 일자를 구분한다.

대량 주문은 분할 배차 가능하다. 지정일 납기에 위험이 있으면 우선배송·대체 배송으로 조치하며 실제 조치 여부는 확인 후 안내한다. 분할 배차가 확정되면 을이 갑에게, 갑이 고객에게 잔여 회차 예상 도착 시점을 미리 고지한다. 정보가 없으면 예상 시점을 만들어 말하지 말고 확인·접수를 진행한다.

## S04 합포장·분할·위치 메모 (제6~9조)

- 상온 농산물과 냉장·냉동 수산물처럼 보관 조건이 다르면 합배송이 제한되고 별도 포장·배송비가 발생할 수 있다. 무조건 합배송 또는 무조건 추가 요금으로 단정하지 않는다.
- 동일 수령지의 출고 전 복수 주문은 합포장할 수 있다. 조건을 확인하고 절감된 초과 배송비는 환불 또는 정산한다. 실제 절감액을 조회한다.
- 고객 요청 분할 배송은 회차별 비용이 발생할 수 있고 **최초 출고일부터 7일 이내·최대 3회차**다. 초과 요청은 별건 주문으로 안내한다. 원문이 규정하지 않은 일수 경계 시각·추가 배송비를 추정하지 않는다.
- 제8조의 고객 요청 분할 제한을 제5조의 대량 주문 배차에 임의 확대하지 않는다.
- 문 앞·경비실·무인함 등 위치 메모는 가능하되 분실·훼손 위험을 사전에 안내한다. 메모가 있다는 이유만으로 모든 사고를 고객 귀책으로 처리하지 않는다.

## S05 반송·재배송비 (제10조)

고객 귀책 반송의 재배송비는 고객 부담이 원칙이다. 사안별 일부(절반 등) 분담이 가능하지만 상담 권한 위임·재량 한도 규정 내에서 결정하고 사유를 상담 기록에 남긴다. 예시 ‘절반’을 고정 할인율로 사용하지 않는다. 귀책, 실제 비용, 권한, 한도가 확인되지 않으면 금액·비율을 확정하지 않는다. 재량 밖 판단은 사업 운영자, 필요한 경우 조합장 순으로 요청한다. 반송 재배송 주소 변경은 S02의 예외를 적용한다.

## S06 파손·배송 완료 미수령 (제11~12조)

배송 중 파손은 을에 파손 클레임을 접수한다. 고객 재배송·환불 등의 구제를 먼저 처리하고 갑·을 정산은 내부로 분리한다. 을 책임 구간이라는 이유로 고객 처리를 늦추거나 고객에게 해결 책임을 전가하지 않는다. 구제 수단·권한은 관련 정책으로 확인하되 내부 책임 정산을 선행 조건으로 만들지 않는다.

배송 완료이나 미수령인 분실은 을에 조사 접수하고, 고객 과실이 아니면 갑이 우선 재발송한다. 완료 표지만으로 실제 수령을 단정하지 않는다. 임의로 조사 종결 후에만 재발송할 수 있다는 조건을 추가하지 않는다. 고객 과실 여부도 근거로 확인하고 추측하지 않는다. 내부 배상 청구·구상은 고객 대화에 노출하지 않는다.

## S07 실제 담당 구간·연락 (S-S03)

|구간|기본 담당·대상·차량|
|---|---|
|교동 산지 집하|교동 배정 기사, 농산 10품목 상온·예냉, TR-KD-01|
|갯마을 산지 집하|갯마을 배정 기사, 수산 2종 냉동, 냉동 탑차 TR-GM-02|
|교동 집하 등록·간선 인계|교동 배정 기사, 전 품목, TR-KD-01|
|간선 이후|을의 간선, 전 품목, 차량·기사 정보 미제공|

갯마을 냉동분도 교동 출하장 경유 후 집하 등록·간선 인계를 거친다. 따라서 냉동분의 해당 인계 담당을 갯마을 기사로 잘못 지정하지 않는다. 기사 부재 시 다른 배정 기사가 대행할 수 있고 실제 구간 인계는 갑의 출하장 인계대장으로 확인한다. 조직관계도가 참조하는 업무 인계·부재 기록도 교차 확인하되 두 기록을 확보했다고 가장하지 않는다.

을이 갑에게 통지하는 것은 배정 기사 성명·담당 구간이며 개인 연락처는 통지 대상이 아니다. 간선 기사 정보는 통지하지 않는다. 배정 기사 연락처는 외부 제공 제한, 간선 연락처는 조합 미보유라는 조직 자료의 차이를 유지한다. 배정 기사도 자신이 직접 관측한 구간 사실만 확인하며 처리 결정·현재 배송 상태 확정 권한은 없다. 소개 절차는 조직 가이드를 따른다.

## S08 처리 결과·미확정·응답

실제 주문 시스템·등록 액션·권한을 확인한 뒤 조회·변경·취소·클레임·조사·재발송·환불·정산을 구분해 수행한다. 접수·승인·실행 완료를 섞지 않는다. 타임아웃 등 결과 불확실 시 상태 조회 없이 쓰기를 재시도하지 않는다. 짧은 답변에도 제한·예외·다음 행동을 남긴다. SimpleText·500자 이내.

계약 시행일, 정식 별표 제목·전체, 상담 재량 금액·비율, 배송비·추가 요금, 정확한 기간 경계, 개별 배송 상태, 실제 API는 미제공이다. 이 문서는 정책 사실의 정리이며 임의 처리 권한을 만들지 않는다.

## S10 구방만 진술 보완: 부재·대행·오프라인 기록

근거: [사용자 제공 원문 G01~G12](../sources/statements/GUBANGMAN_TRANSCRIPT.md). 배송 사실 확인 담당으로 S01~08·공통 SimpleText 500자 규칙을 함께 적용한다. 진술 확보와 대장·스캔 직접 확인을 구분한다.

- 구방만은 시원배송 소속 교동 배정 기사이며 조합 직원이 아니다. 생산자는 1차 포장, 구방만은 출하 포장·교동 농산10품목 집하(TR-KD-01)를 맡는다. 교동의 전 품목 집하 등록·간선 인계도 담당한다. 갯마을 냉동분은 TR-GM-02로 갯마을→교동 출하장 이동 후 등록된다. 차량 정보만으로 실제 온도·사고 귀책을 확정하지 않는다.
- 6/23~25 육지 방문 중 출고일에 겹친 부재는 6/24 하루 종일이다. 그날 박민아에게 집하·배송 대행을 맡겼다는 진술이다. 3일간 출고 중단이나 대행 미수행으로 확대하지 않는다. 전화 인계만 했고 사전 부재 신청·서면 인계서·본인의 해당 날짜 대장 기재가 없다고 진술했다.
- 인계대장은 조합 사무실 종이 대장으로 온라인 조회 불가다. S07의 대장 확인은 현장 확인 경로로 적용한다. 확인 가능한 조합 담당자에게 날짜·구간·작성자·인계 내용을 요청한다. 없는 온라인 대장 API나 운행 수첩을 조회하지 않는다. 실제 문의 수단이 없으면 확인 필요 상태로 안내한다.
